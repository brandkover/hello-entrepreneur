# Hola Emprendedor

Es un plugin simple e inspirador para emprendedores. Muestra una frase motivacional aleatoria en la parte superior de tu panel de administración de WordPress.

## Versión 1.2.0

Esta actualización confirma compatibilidad con WordPress 7.0, sincroniza la versión usada para los estilos y añade el filtro `hola_emprendedor_quotes` para personalizar frases sin modificar el archivo principal del plugin.
